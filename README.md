# Students' Centre

Students' Centre is an academic and social learning platform designed to connect students, support collaboration, and make learning resources more accessible.

## Project Structure

- `frontend/` — React Native application built with Expo.
- `backend/` — Node.js, Express, and TypeScript API.
- `frontend/android/` — Android native project.
- `frontend/ios/` — iOS native project.

## Frontend

Run the following commands from the frontend directory:

```bash
cd frontend
npm install
npm start
```

## Backend

Run the following command from the backend directory:

```bash
cd backend
npm install
```

Configure the required environment variables before starting the backend.

## Development

The frontend and backend have separate dependency configurations. Install dependencies within their respective directories.
